# McOsu AP Points Helper

Desktop GUI-приложение, Discord-бот и веб-дашборд для отслеживания и расчёта AP (Activity Points) в osu! стандарте через McOsu или osu! stable.

---

## Возможности

**GUI приложение** (customtkinter):
- **Control** — запуск Discord бота и веб-сервера из одного окна, переключение источника скоров (McOsu / osu! stable)
- **Last Score** — загрузка последнего сыгранного скора с полной статистикой: точность, PP, AP, грейд, комбо, моды, разбивка по хитам (300/100/50/miss). Вкладка профиля игрока: взвешенный PP, количество игр, средняя точность, максимальное комбо, распределение грейдов. Режим автосканирования для отслеживания новых скоров в реальном времени
- **AP Breakdown** — детальный разбор расчёта AP с каждым множителем и его вкладом в финальный результат

**Discord бот**:
- Команда `!rs` (или `!last`) — отправляет в чат embed-карточку последнего скора с AP, PP, точностью, грейдом, модами, хит-каунтами и ссылкой на карту

**Веб-сервер** (FastAPI + uvicorn, порт 8080):
- Главная страница — дашборд со статистикой
- `GET /api/daily` — ежедневная сводка AP (сумма, количество скоров, лучший скор)
- `GET /api/scores?date=YYYY-MM-DD` — список скоров за указанную дату, отсортированных по AP
- `GET /api/profile?goal=ЧИСЛО` — профиль игрока: общий AP, взвешенный PP, количество игр, выполненные дневные цели, распределение грейдов, топ-5 скоров

**Поддерживаемые источники скоров**:
- McOsu — чтение `scores.db` из папки McOsu
- osu! stable — чтение `scores.db` из папки osu!

Все скоры сохраняются в локальную SQLite-базу (`scores_ap.db`) с защитой от дубликатов.

## Установка и запуск

### Требования
- Python 3.10+
- Установленные зависимости из `mcsu_bot/requirements.txt`

### Настройка
1. Скопируйте `config.example.json` в `config.json`
2. Заполните поля:
   - `discord_token` — токен Discord-бота (https://discord.com/developers/applications)
   - `osu_client_id` и `osu_client_secret` — API-ключи osu! (https://osu.ppy.sh/home/account/edit#new-oauth-application)
   - `scores_db_path` — путь к `scores.db` от McOsu или osu! stable
   - `songs_dir` — путь к папке `Songs` osu! (для поиска .osu-файлов)
   - `source` — `"mcsu"` или `"osu"` (источник скоров)

### Запуск из исходников
```bash
pip install -r mcsu_bot/requirements.txt
python launcher.py
```

Только Discord-бот: `python -m mcsu_bot.main`
Только GUI: `python -m mcsu_bot_gui`

### Сборка .exe
```bash
pip install pyinstaller
pyinstaller --clean build.spec
```
Готовый `dist/McOsuTracker.exe` можно запускать без Python.

## Как работает формула AP

AP (Activity Points) — это собственная метрика, которая оценивает результат не только по точности, но и по сложности карты, комбо, модам и другим факторам.

Формула выглядит так:

`AP = base_value * acc_mult * combo_ratio * miss_penalty * mod_mult * (1 + density_bonus) * (1 + aim_bonus) * (1 + rank_bonus)`

Разберём каждый компонент:

**Base (база)** — `total_hits * star_rating * 0.1`
Чем больше объектов на карте и чем выше звездность, тем выше база. Коэффициент 0.1 подобран эмпирически.

**Accuracy (точность)** — точность возводится в квадрат. Это значит, что игроки с высокой точностью получают значительно больше AP, а ошибки наказываются сильнее, чем в обычном PP.

**Combo Ratio** — отношение вашего максимального комбо к максимально возможному на карте. Если вы прошли карту с полным комбо — множитель равен 1.0. Чем больше сбросов комбо, тем сильнее падает множитель.

**Miss Penalty** — штраф за промахи. Каждый мисс уменьшает финальный результат. Чем больше миссов, тем ниже множитель.

**Mod Multiplier** — бонус за использование модов. Каждый мод даёт свой процент прибавки: Easy +5%, Hidden +8%, HardRock +12%, DoubleTime +15%, Flashlight +6%. Если модов нет, множитель равен 1.0 (NM — No Mod).

**Density Bonus (бонус плотности)** — если плотность объектов на карте превышает 2 объекта в секунду, даётся дополнительный бонус (до +30%). Плотные карты (спритмы) ценятся выше. Рассчитывается как `(density - 2.0) * 0.04`.

**Aim Bonus (бонус аима)** — если аим-звёздность карты выше спид-звёздности, даётся бонус за сложное аиминг. Рассчитывается как `(stars_aim / stars_speed - 1.0) * 0.08`, максимум +15%. Это выделяет карты, где сложность именно в аиме, а не в скорости.

**Rank Bonus** — дополнительный бонус за высокий грейд: +20% за X или XH, +10% за S или SH. Остальные грейды бонуса не дают.

Итоговый AP округляется до целого числа и сохраняется в базу данных вместе с полной информацией о скоре.

## Использование Discord бота

После запуска бота (через GUI или `python -m mcsu_bot.main`) отправьте в канал:

- `!rs` или `!last` — показать последний сыгранный скор с расчётом AP

Бот создаёт embed-сообщение с названием карты, AP, PP, точностью, грейдом, комбо, хит-каунтами, модами и кнопкой-ссылкой на карту.

---

## Использование веб-сервера

При запуске веб-сервера (через GUI или вместе с `launcher.py`) дашборд доступен по адресу `http://localhost:8080`.

API-эндпоинты можно использовать для интеграции с другими сервисами или для кастомных дашбордов.
