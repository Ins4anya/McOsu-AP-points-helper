# McOsu AP Points Helper

Desktop GUI-приложение, Discord-бот и веб-дашборд для отслеживания и расчёта AP (Activity Points) в osu! стандарте через McOsu или osu! stable.

---

## Возможности

**GUI приложение** (customtkinter):
- **Control** — запуск Discord бота и веб-сервера из одного окна, переключение источника скоров (McOsu / osu! stable)
- **Last Score** — загрузка последнего сыгранного скора с полной статистикой: точность, PP, AP, грейд, комбо, моды, разбивка по хитам (300/100/50/miss). Вкладка профиля игрока: взвешенный PP, количество игр, средняя точность, максимальное комбо, распределение грейдов. Режим автосканирования для отслеживания новых скоров в реальном времени
- **AP Breakdown** — детальный разбор расчёта AP с каждым множителем и его вкладом в финальный результат

**Discord бот**:
- Команда `!rs` (или `!last`) — отправляет в чат embed-карточку последнего скора с AP, PP, точностью, грейдом, модами, хит-каунтами и ссылкой на карту

**Веб-сервер** (`server/`, FastAPI + SQLAlchemy + Alembic, порт 8000):
- OAuth-вход через osu! и публичные профили игроков (таблица лидеров, страница скора)
- Daily Challenge — «бинго» из 5 карт + персональный режим по локальной библиотеке
- Streak с восстановлением пропущенного дня, радар скиллов и бейджи
- Загрузка баннера и флага профиля, цели (daily goal / on-fire)

**Локальный дашборд** (`web/`, FastAPI, порт 8080, legacy):
- Главная страница — дашборд со статистикой
- `GET /api/daily` — ежедневная сводка AP (сумма, количество скоров, лучший скор)
- `GET /api/scores?date=YYYY-MM-DD` — список скоров за указанную дату, отсортированных по AP
- `GET /api/profile?goal=ЧИСЛО` — профиль игрока: общий AP, взвешенный PP, количество игр, выполненные дневные цели, распределение грейдов, топ-5 скоров

**Поддерживаемые источники скоров**:
- McOsu — чтение `scores.db` из папки McOsu
- osu! stable — чтение `scores.db` из папки osu!

Все скоры сохраняются в локальную SQLite-базу (`scores_ap.db`) с защитой от дубликатов.

## Установка и запуск

### Требования
- Python 3.10+
- Установленные зависимости из `mcsu_bot/requirements.txt`

### Настройка
1. Скопируйте `config.example.json` в `config.json`
2. Заполните поля:
   - `discord_token` — токен Discord-бота (https://discord.com/developers/applications)
   - `osu_client_id` и `osu_client_secret` — API-ключи osu! (https://osu.ppy.sh/home/account/edit#new-oauth-application)
   - `scores_db_path` — путь к `scores.db` от McOsu или osu! stable
   - `songs_dir` — путь к папке `Songs` osu! (для поиска .osu-файлов)
   - `source` — `"mcsu"` или `"osu"` (источник скоров)
   - `share_local_beatmaps` — `true`/`false` (необязательно, по умолчанию `false`). При `true` клиент передаёт серверу список ID карт из `songs_dir` для персонального Daily Challenge и отметки «Скачана». Этот же флаг можно переключить галочкой в разделе Server Sync.

### Запуск из исходников
```bash
pip install -r mcsu_bot/requirements.txt
python launcher.py
```

Только Discord-бот: `python -m mcsu_bot.main`
Только GUI: `python -m mcsu_bot_gui`

### Сборка .exe
```bash
pip install pyinstaller
pyinstaller --clean build.spec
```
Готовый `dist/McOsuTracker.exe` можно запускать без Python.

## Как работает формула AP

AP (Activity Points) — это собственная метрика, которая оценивает результат не только по точности, но и по сложности карты, комбо, модам и другим факторам.

Формула выглядит так:

`AP = max(0, base * acc_mult * combo_ratio * miss_penalty * mod_mult * (1 + density_bonus) * (1 + aim_bonus) * (1 + score_bonus) * (1 + rank_bonus))`

Расчёт выполняется в `mcsu_bot/ap_calculator.py` (`explain_ap`). Если `total_hits == 0` или звёздность равна нулю, AP равен 0.

Разберём каждый компонент:

**Base (база)** — `objects * star_rating * 0.1`, где `objects` — это взвешенное количество объектов карты: каждая нота (круг) считается за 1, слайдер за 2 (начало и конец), спиннер за 1. Например, карта с 250 нотами и 250 слайдерами даёт вес `250 + 250*2 = 750`. Если информацию об объектах получить не удалось, используется `total_hits` (количество сыгранных хитов). Звёздность берётся с учётом модов (`rosu_pp_py`), а при её отсутствии — из метаданных карты.
Коэффициент 0.1 подобран эмпирически.

**Accuracy (точность)** — `accuracy ^ 1.2`. Высокая точность даёт заметно больше AP, а ошибки наказываются сильнее, чем линейно.

**Combo Ratio** — `sqrt(max_combo / max_possible_combo)`. Если полное комбо карты неизвестно, множитель принимается равным 1.0 и не снижает AP. Поэтому для корректного результата полное комбо должно передаваться из `pp_result` (это делают GUI и Discord-бот).

**Miss Penalty** — `max(0, 1 - 0.3 * misses / total_hits)`. Каждый мисс уменьшает результат пропорционально доле промахов.

**Mod Multiplier** — бонус за использование модов. Каждый мод даёт свой процент прибавки: Easy +5%, Hidden +8%, HardRock +12%, Flashlight +6%. Для DoubleTime и Nightcore бонус +15% применяется, если скорость неизвестна. Если известна скорость (`speed_mult`), бонус скорости масштабируется: `0.15 * (rate - 1) / 0.5`. Замедление (HalfTime) бонуса не даёт. Если модов нет, множитель равен 1.0 (NM — No Mod).

**Density Bonus (бонус плотности)** — `density = total_hits / длительность_карты_с_учётом_скорости`. Если density превышает 2 объекта в секунду, добавляется `(density - 2.0) * 0.04`, но не более +15%. Длительность локальной карты оценивается приблизительно, поэтому бонус для карт, найденных только в локальной папке Songs, может отличаться от точного значения.

**Aim Bonus (бонус аима)** — `aim_ratio = stars_aim / max(stars_speed, 0.01)`. Если `aim_ratio` выше 1.0, добавляется `(aim_ratio - 1.0) * 0.50`, максимум +30%. Это выделяет карты, где сложность именно в аиме, а не в скорости.

**Score Bonus (бонус за очки)** — действует только на аим-карты (`aim_ratio >= 1.15`) и добавляет `score / 1 000 000 * 0.01` при ненулевом счёте.

**Rank Bonus** — дополнительный бонус за высокий грейд: +20% за X или XH, +10% за S или SH. Остальные грейды бонуса не дают.

AP сохраняется в базу данных как вещественное число без округления. В интерфейсе и Discord-сообщениях он отображается с округлением до целого.

## Использование Discord бота

После запуска бота (через GUI или `python -m mcsu_bot.main`) отправьте в канал:

- `!rs` или `!last` — показать последний сыгранный скор с расчётом AP

Бот создаёт embed-сообщение с названием карты, AP, PP, точностью, грейдом, комбо, хит-каунтами, модами и кнопкой-ссылкой на карту.

---

## Использование веб-сервера

Основной сервер (`server/`) слушает порт **8000** (публично — через туннель `ap.ins4anya.fun`), оверлей — порт 8001. Запуск: `run_server.bat` / `run_overlay.bat`. Локальный дашборд (`web/`) доступен на **8080** (через GUI или `launcher.py`).

API-эндпоинты можно использовать для интеграции с другими сервисами или для кастомных дашбордов.
